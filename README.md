# Compiler Design Project

## Overview

This repository contains the development of a compiler as part of our Computer Science group project. The project will explore the major phases involved in translating source code into a target representation.

## Project Objectives

* Implement lexical analysis to identify tokens.
* Implement syntax analysis to check grammatical structure.
* Perform semantic analysis to check program meaning and consistency.
* Generate an intermediate representation.
* Generate target code according to the project requirements.
* Apply code optimization techniques where required.

## Technologies

* **Programming Language:** C++
* **Version Control:** Git and GitHub
* **Build System:** To be confirmed

## Project Phases

1. Lexical Analysis
2. Syntax Analysis
3. Semantic Analysis and Intermediate Representation
4. Code Generation
5. Code Optimization
